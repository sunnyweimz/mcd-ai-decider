## 💡 这是什么

市面上的点餐助手大多是"查询器"——你问它答，菜单甩给你，选还是你自己选。

**麦麦决策官不一样。它是一套完整的、可解释的个性化点餐推荐引擎。** 它把工业界推荐系统的标准范式搬进点餐场景，而不只是查菜单：

```
                    ┌──────────── 用户画像(记忆) 随反馈更新 ───────────┐
                    ↓                                                 │
特征采集 → 多路召回 → 多目标精排 → 可解释重排 → 真实核价下单 → 反馈学习 ┘
 (画像)   (4路并行)  (6维加权打分)  (MMR+反事实)   (calculate-price)  (EE探索)
                    ※ 全程旁路产出"决策链路快照"，推荐过程可追溯
```

你只需要说一句「一个人，预算 30，中午吃点啥」，剩下的交给它。它会读你的历史建画像、按场景动态加权、给带理由和反事实解释的 Top3，并在你说"换一个/太贵了/吃腻了"时越用越懂你。

> 完整的推荐系统设计拆分在 [`engine/`](./engine) 目录（架构、召回、精排模型、重排解释、画像、反馈EE、冷启动、决策追踪）。

## ✨ 核心亮点

- 🧠 **真·个性化**：读你的真实历史订单，提炼口味画像和价格锚点。它知道你是"板烧鸡腿堡老朋友"，而不是只会推全店热销。
- 🎯 **多目标决策**：口味匹配 × 性价比 × 热量约束 × 券契合 × 新鲜度，综合打分给出 Top3，而不是一个敷衍的答案。
- 💰 **自动薅羊毛**：主动盯住你"今天到期的券"和"快过期的积分"，把隐性浪费显性化——"再不用就没了"。
- 🗣️ **会讲人话的理由**：每个推荐都有 reason code。"你最近 3 单有 2 单点板烧，这次换个新口味不腻"——你知道它为什么这么推。
- 🥗 **健康也兼顾**：接入官方 160+ 餐品营养数据，支持"控热量/要扛饿"模式，馋麦当劳也能吃得明白。
- 🛒 **一下到底**：从"吃什么"一路带到真实核价、一键下单、支付引导，不是半截子建议。
- 🔄 **会学习（反馈闭环 + EE）**："太贵了"→下一轮自动压价；"吃腻了"→提高探索、给你没吃过的新品。基于 ε-greedy 的探索与利用，兼顾稳妥和惊喜。
- 🔍 **决策透明可追溯**：问它"你怎么推的"，它能把"召回了多少→排除了什么→为什么是它"分层讲清楚，不是黑盒。

## 🚀 安装与使用

### 1. 申请麦当劳 MCP Token
参考 [麦当劳 MCP Server 使用指南](https://github.com/M-China/mcd-mcp-server)，在开放平台控制台激活并复制你的 Token。

### 2. 配置 MCP（以支持 MCP 的 AI 客户端为例）
把 [`mcp-config.example.json`](./mcp-config.example.json) 里的 `${MCD_MCP_TOKEN}` 换成你的真实 Token（放到环境变量里，别写进仓库）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer ${MCD_MCP_TOKEN}" }
    }
  }
}
```

### 3. 加载 Skill
把 [`SKILL.md`](./SKILL.md) 作为系统提示 / Skill 载入你的 AI Agent（Claude、Kiro、WorkBuddy 等支持 MCP 的环境均可）。

### 4. 开始对话
直接说出你的需求即可，例如：
- 「在南京，一个人，预算 30 以内，帮我决定中午吃啥」
- 「我想吃麦当劳但在减脂，热量控制在 700 以内，给我搭一套」
- 「我手里有啥券快过期了？用上最划算的帮我下单」
- 「老样子，但换个没吃过的口味」

## 🎬 运行示例（真实 MCP 调用）

> 下面是一次真实对话。用户画像、券、积分、菜单均来自麦当劳官方 MCP 实时返回。

**用户：** 在南京，一个人，预算 30 以内，中午到店自取，帮我决定吃啥。

**麦麦决策官：**

> 先帮你把今天的情况摸了一遍 👇
> **南京 · 1 人 · 到店自取 · 预算 ~30 · 午餐时段（周五）**
> 读了你最近的订单：你是**板烧鸡腿堡 / 双层吉士**的老朋友，爱配薯条和小食，常走到店自取，客单价基本在 15~37 之间。
> ⚠️ 顺手帮你盯了两件事：你有 **351.9 积分已经过期**了（可惜），另外手里 **「薯薯任选 ¥9.9」和「麦旋风任选 ¥9.9」今天到期**，不用就没了。
>
> 给你三套方案，带理由：
>
> 🥇 **主推｜板烧鸡腿堡随心配 + 薯薯任选（券）**
> 约 ¥24（含今日到期券）· 命中你的口味主线，又把今天到期的薯券用掉，省得浪费。扛饿、不踩雷。
>
> 🥈 **惊喜｜换个新口味：泰式/韩式风味堡 + 麦旋风（今日到期券 ¥9.9）**
> 约 ¥25 · 你最近没点过的口味，解腻；麦旋风券也到期了，一起消化。
>
> 🥉 **极致省｜双层吉士随心配 ¥14.9 档**
> 约 ¥15 · 你点过多次的稳妥低价组合，预算压到一半，钱包友好。
>
> 想按 🥇 下单吗？我直接帮你核到手价并下单；也可以说"换"或"调预算"。

**用户：** 就主推，帮我下单。

**麦麦决策官：** 好嘞，正在用真实接口核价（券后价）→ 确认门店可售 → 生成订单 → 给你支付链接 ✅
